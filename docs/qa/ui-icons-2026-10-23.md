## Implementation and integration

Lucide was already used by the newer player and layout components. The old imports spanned 13 react-icons sets across 53 components. Import aliases retain local names to keep this change limited to rendering. The two remaining react-icons imports are brand logos, not application controls. No dependency, playback behavior, release security or native binary changes are included.

Shared sizing rules live in src/app/globals.css. Settings headers use the same settings-app-icon class. Broad :where selectors have zero specificity so explicit utility and component styles still win. Larger artwork and transport icons keep their existing dimensions. Inline/text icons use 1em where that preserves existing layout.

The renderer flow ends at SVG presentation: existing event handlers, accessibility labels, API requests, reducers, native bridge commands and release checks remain connected to the same callers. Windows / Android app contexts use the shared website UI; these changes do not deliver a new native executable or APK. Source changes cover 57 JSX components plus globals.css; the PR's file list contains the complete inventory.
